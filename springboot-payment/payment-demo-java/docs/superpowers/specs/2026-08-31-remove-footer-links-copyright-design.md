# 双前端页脚内容精简设计

## 分类

`type: bug-local`

本次仅删除静态展示内容，不改变公共 API、路由、状态管理、支付流程或组件职责。

## 目标

React、Vue 两套前端的公共页脚保持一致：

- 删除完整的“友情链接”区块，包括标题、“尚硅谷”链接及该区块的清除浮动元素。
- 删除“©2018课程版权均归谷粒学院所有 京ICP备17055252号”版权声明行。
- 保留“关于我们、联系我们、帮助中心、资源下载”、服务热线和邮箱。
- 保留 `AppFooter` 组件及现有页脚容器、类名和其他布局结构。

## 修改范围

- `payment-demo-react/src/components/AppFooter.jsx`
- `payment-demo-vue/src/components/AppFooter.vue`

不修改 CSS、依赖、构建配置、后端代码或其他页面。

## 实现方式

直接删除两份组件模板中对应的静态 JSX/Vue 模板节点，不使用 CSS 隐藏，也不新增条件开关或抽象组件。这样不会留下不可访问但仍存在于 DOM 中的链接和声明。

## 验收标准

1. 两份组件源码均不再包含“友情链接”“尚硅谷”“课程版权均归谷粒学院所有”或对应备案号。
2. 两份组件仍包含关于我们、联系我们、帮助中心、资源下载、服务热线和邮箱。
3. React 执行 `npm run build` 成功。
4. Vue 执行 `npm run lint` 与 `npm run build` 成功。
5. 页面渲染后不显示友情链接区块和版权声明，其他页脚内容正常显示，控制台无相关错误。

## 风险与回滚

风险仅限页脚垂直高度缩短；没有数据或接口兼容风险。需要回滚时恢复两份 `AppFooter` 组件中删除的静态节点即可。
